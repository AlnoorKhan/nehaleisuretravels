# Neha's Leisure Travels

Website for Neha's Leisure Travels — customised domestic & international holidays.
*Let's make happy memories together. ❤️*

## Structure
- `index.html` — the full single-page site (HTML, CSS and JS inline; no build step)
- `assets/neha.jpg` — Neha's portrait (add it)
- `assets/hero.jpg` — hero banner image (add it)
- `assets/destinations/*.jpg` — destination photos; see `assets/destinations/README.txt` for file names

Images that are missing fall back to colour gradients, so the site works without them.

## Enquiry form
The quote form opens WhatsApp (8082634044) with the trip details pre-filled — no server needed.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy
Works on any static host — GitHub Pages (Settings → Pages → deploy from `main`), Netlify or Vercel.
